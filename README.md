# Threat Analysis, Risk Assessment & Incident Response Playbook (Bangladesh Bank Case Study)

This repository contains independent, OSINT-based cybersecurity threat analyses and operational frameworks modeled after the historic 2016 SWIFT cyber heist at Bangladesh Bank. 

> **Academic & Professional Notice:** These documents are independent, illustrative risk assessments and incident response playbooks created solely for professional portfolio purposes. They are based entirely on publicly available open-source intelligence (OSINT), forensic reports, and media investigations.

## 📂 Repository Contents

### 1. Risk Assessment Report & Incident Response Playbook
- **File:** `Bangladesh Bank Risk Assessment Report and Incident Response Playbook.pdf`
- **Highlights:** 
  - Asset-based risk matrix evaluating SWIFT terminals, operator credentials, verification printers, and logging systems.
  - Quantitative likelihood and impact scoring.
  - Dual framework mapping linking vulnerabilities to **NIST Cybersecurity Framework (CSF)** and **MITRE ATT&CK** techniques.
  - An 8-phase operational Incident Response Playbook featuring emergency SWIFT gateway isolation protocols and step-by-step flowchart logic
